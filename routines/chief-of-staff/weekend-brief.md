# Routine: Weekend Brief (Saturdays 06:43; must be saved by 07:00)

Agent: Chief of Staff. Read `CLAUDE.md` and `.claude/agents/chief-of-staff.md` first.

ONE short message. Weekends stay light: only what genuinely matters.

1. **Urgent only:** Gmail since Friday morning: list 🔴 items only (with a draft if a reply is needed before Monday). Count everything else.
2. **This weekend:** calendar events that need preparation or are time-critical today and tomorrow (collections, deliveries, social plans, travel).
3. **Deadline radar:** anything due in the next 7 days (see the morning-brief routine, step 6).
4. **Agent Outbox:** Urgent/Today items only; mark them "Included in message".
5. **Inbox clean-up suggestions (max 5):** senders she never opens or that clutter the inbox, each with the suggested action (unsubscribe link found in the email, or a Gmail filter rule written out). She applies them herself. NEVER suggest filtering or hiding job-alert or recruiter emails (StepStone, Totaljobs, Indeed, LinkedIn, Glassdoor, freelancermap, recruiters). Never create filters, unsubscribe or click links.
6. Last line: a friendly nudge to log this weekend's bank/card transactions and any net-worth change in the "my-accountant" Google Sheet.

Safety: as in the morning brief. Finish with one Agent Run Log row (Routine = weekend-brief).

Also include the Learning Agent's 🗣️ language lesson from the Outbox (one line per language).
